# Brain Tumor MRI Image Classification

Deep-learning project that classifies brain MRI images into four classes (**glioma, meningioma, no\_tumor, pituitary**).
A custom CNN is built from scratch and compared with three ImageNet-pretrained models (transfer learning). The best model is served through a Streamlit web app that shows the predicted tumor type and a confidence score.

> \\\*\\\*Educational project. Not a medical diagnosis tool.\\\*\\\* Always consult a qualified radiologist or doctor.

**Note on the Custom CNN.** The first run of the custom CNN failed (it predicted only one class, 32.5% accuracy). The cause was a mismatch between BatchNorm statistics and the brightness augmentation on dark MRI images. It was fixed by (1) BatchNorm momentum 0.9, (2) removing the brightness augmentation, (3) slightly lower dropout, and retrained in `Custom\\\_CNN\\\_.ipynb`. The main notebook still contains the original failed run for transparency.

## Dataset

Brain Tumor MRI Multi-Class dataset (provided with the project brief): 2,443 images, all 640x640 RGB.

|Split|Images|
|-|-|
|train|1,695 (glioma 564, meningioma 358, no\_tumor 335, pituitary 438)|
|valid|502|
|test|246 (glioma 80, meningioma 63, no\_tumor 49, pituitary 54)|

No corrupt files and no duplicate images (also none shared between splits). Class imbalance is mild (largest/smallest ratio 1.67) and handled with balanced class weights.

## Method

1. Dataset audit: class balance, resolution, corrupt files, exact duplicates, leakage between splits.
2. Preprocessing: resize to 224x224, pixel normalisation inside the model (the saved `.h5` accepts raw images).
3. Augmentation (training only): flips, rotation, zoom, shift (and brightness for the transfer models).
4. Models: custom CNN (4 conv blocks, BatchNorm, MaxPool, Dropout) and MobileNetV2 / EfficientNetB0 / InceptionV3 with a new classification head.
5. Training: head first, then fine-tuning of the top 40 backbone layers at learning rate 1e-5. Callbacks: EarlyStopping, ModelCheckpoint, ReduceLROnPlateau.
6. Evaluation: accuracy, precision, recall, F1, confusion matrix, training curves, most confident mistakes, confidence histogram.

## Run the app

```bash
pip install -r requirements.txt
streamlit run app.py
```

Use Python 3.10-3.12 (TensorFlow may not install on newer versions). Upload an MRI image; the app shows the predicted tumor type, the confidence and the probability of every class. A warning appears when confidence is below 60%.

## Limitations

* Trained and tested on a single public dataset; it has not been validated on scans from other hospitals or scanners.
* Mean image brightness differs clearly between classes (glioma darkest, no\_tumor brightest), so a model could partly rely on exposure instead of the tumor itself.
* Meningioma is the hardest class for the selected model (F1 0.76) and for the custom CNN (recall 0.48).
* The confidence score is the model's softmax output and is not a calibrated clinical probability.
* Custom CNN often confuses meningioma with glioma and can be confidently wrong, so MobileNetV2 was chosen for deployment.
